# UnitC シフト管理（TrainerHub）

公開URL: https://unitc-shift.vercel.app

7名分のシフト・稼働ログを全員で共有できるツール。元は1ファイル完結のプロトタイプ（`window.storage` を使用）だったものを、Vercelにデプロイし、実データを全員で共有できるよう構成し直したもの。

## 主な機能

- メンバー（7名）ごとのロール（わざ）・工数・シフト申請の入力と全員共有
- **全員のステータス盤**：選択中の月について、全員の「申請合計 / 推奨」を一覧表示
- **推奨超過アラート**：推奨時間を超えたメンバーがいると、画面上部に赤いアラートで全員に表示（超過者と超過時間つき）
- **スプレッドシート出力**：全員×全月の記録（推奨・申請・差分・超過判定・申請状況・相談）を CSV でダウンロード（Excel / Google スプレッドシートで開ける）

## 構成

- `index.html` — フロントエンド（見た目・操作はプロトタイプのポケモン風UIを維持）
- `api/members.js` — サーバーレスAPI。メンバーごとのデータを Vercel Edge Config に保存/取得する
  - データはメンバーID単位（`member_<id>`）で保存されるため、1人の保存が他メンバーのデータを上書きすることはない
  - 保存領域（Edge Config ストア `unitc-shift-store`）は、初回アクセス時に自動生成される（手動セットアップ不要）
- `package.json` — 依存なしの最小構成

## データの流れ

1. ブラウザが `GET /api/members` で全員分のシフトを取得
2. 「セーブ」ボタンで `POST /api/members`（選択中メンバー分のみ）を送信
3. サーバーレス関数が Vercel Edge Config に読み書きし、全員に共有される
4. 「🔄 最新を取得」で他メンバーの最新データを再取得できる
5. 「📊 スプレッドシートに出力」でその時点の全記録を CSV としてダウンロード（記録の保存用）

## 記録（スプレッドシート）について

- ライブデータは Vercel Edge Config が保持（全員共有）。
- 「スプレッドシートに出力」ボタンで、全員×全月の記録を CSV で書き出せる。UTF-8 BOM 付きなので Excel でも文字化けせず、Google スプレッドシートにもそのまま取り込める。
- 列：メンバー / 月 / わざ合計(推奨h) / 申請合計h / 差分h / 判定(超過・OK・未申請) / 前半申請 / 後半申請 / 相談理由 / 補足メモ。

## ホスティング / 環境変数

- Vercel プロジェクト（`ai-div` アカウント配下）にデプロイ。公開URL `https://unitc-shift.vercel.app`。
- Deployment Protection（ログイン要求）は無効化済み＝URLを知っていれば誰でも閲覧・編集できる。
- `api/members.js` は Edge Config 読み書き用のトークンを `VERCEL_API_TOKEN` 環境変数から読む。リポジトリにはトークン値をコミットしない（デプロイ済みビルドにはインラインのフォールバックを含むが、それはコミットしない）。

## 再デプロイ

`index.html` / `api/members.js` を変更したら、Vercel プロジェクト `unitc-shift-manager` に再デプロイする。

## 注意

- ログイン機能はなく、URLを知っていれば誰でも閲覧・編集できる（社内共有用）。アクセス制限が必要な場合は別途認証の追加が必要。
- Edge Config は少人数・低頻度更新向け。7名のシフト用途では十分。
