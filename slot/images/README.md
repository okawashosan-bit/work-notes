# 画像素材の置き場所

このフォルダに、以下のファイル名で画像をアップロードしてください。

| ファイル名 | 内容 | ポイント |
|---|---|---|
| `frame.png` | 窓枠（SHO-SAN）素材 | — |
| `sym1.png` | 絵柄1（いちばん高得点） | 500 |
| `sym2.png` | 絵柄2 | 300 |
| `sym3.png` | 絵柄3 | 200 |
| `sym4.png` | 絵柄4 | 120 |
| `sym5.png` | 絵柄5（追加予定） | 70 |
| `sym6.png` | 絵柄6（追加予定） | 40 |

- ファイル名は上記のとおり半角英数字にしてください（大文字小文字も一致させる）。
- `frame.png` を置くと、ゲームの枠が自動でその画像に切り替わります。
- 画像がまだ無いファイルは、ゲーム内で絵柄名の文字として表示されます。
