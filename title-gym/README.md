# 🏋️ タイトル発想ジム

Instagram運用で「AIにタイトルを丸投げ → 思考力が衰える」を防ぐための学習ツール。
**使うほど「自分の客に効くタイトルの型」が、自分の中とアプリの中に同時に貯まる**のが狙い。

## 使い方（3秒で起動）

1. `title-gym/index.html` を**ダブルクリック**してブラウザで開くだけ。
2. データはブラウザに自動保存される（サーバー不要）。

## 学びが貯まる5ステップ

| STEP | 内容 | なぜ大事か |
|------|------|-----------|
| 1 | お題（誰に・何を）を決める | ゴールが先。プロは必ずここから |
| 2 | **まず自分でタイトルを考える** | ここが思考の筋トレ。AI画面はロックされる |
| 3 | AIに「型＋理由つき」で提案させる | 案だけだと学びゼロ。なぜ効くかを言語化させる |
| 4 | 採用と理由を記録 | 自分案／AI案/ミックスのどれをなぜ選んだか |
| 5 | 投稿後の数字＋学びを追記 | 数字とひも付いて初めて「知見」になる |

→ 集計された結果は **「💡知見集」タブの効いた型ランキング** に自動反映される。

## データのバックアップ

ブラウザのデータは消えることがあるので、ときどき「📚記録一覧」から
**JSONバックアップ** か **Markdown書き出し** をしておくと安心。
